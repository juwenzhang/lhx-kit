# express-svc-smoke

> Generated by `lhx-cli create --template=express-service` on 2026.

A TypeScript Express service. Database, cache, Docker, and structured logging
are wired in at scaffold time.

## Quick start

```bash
cp .env.example .env
pnpm install
pnpm dev          # starts on http://localhost:3000
curl http://localhost:3000/healthz
```

## Scripts

| Script | What it does |
| --- | --- |
| `pnpm dev` | tsx watch (auto-reload on edits) |
| `pnpm build` | `tsc` → `dist/` |
| `pnpm start` | `node dist/server.js` (prod) |
| `pnpm typecheck` | tsc --noEmit |
| `pnpm lint` | biome check |

## Docker

```bash
docker compose up --build
```

`docker-compose.yml` includes the database / cache services that match the
`db-*` / `cache-*` features you selected at scaffold.

## Structure

```
src/
├── server.ts       # entry — wires app + graceful shutdown
├── app.ts          # express app factory; middlewares + routers
├── env.ts          # zod-validated env (parses on import)
├── logger.ts       # pino logger (pretty in dev)
└── routes/
    └── health.ts   # GET /healthz
```
