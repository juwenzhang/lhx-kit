# fastify-svc-smoke

> Generated by `lhx-cli create --template=fastify-service` on 2026.

A Fastify 5 + TypeScript service.

## Quick start

```bash
cp .env.example .env
pnpm install
pnpm dev
curl http://localhost:3000/healthz
```

## Scripts

| Script | What it does |
| --- | --- |
| `pnpm dev` | tsx watch (auto-reload) |
| `pnpm build` | tsc → dist/ |
| `pnpm start` | node dist/server.js (prod) |
| `pnpm typecheck` | tsc --noEmit |
| `pnpm lint` | biome check |

## Docker

```bash
docker compose up --build
```

## Structure

```
src/
├── server.ts       # entry — start Fastify + graceful shutdown
├── app.ts          # buildApp() — registers plugins + routes
├── env.ts          # zod-validated env
├── logger.ts       # pino logger (also used by db/cache features)
└── routes/
    └── health.ts   # GET /healthz (FastifyPlugin)
```
